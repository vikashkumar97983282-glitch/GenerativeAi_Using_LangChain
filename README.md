## 🧠 Topics I'm Learning

### 1. Generative AI

Understanding the fundamentals of Generative AI and how AI models can generate:

* Text
* Answers
* Summaries
* Code
* Structured information
* Other AI-generated content

### 2. Large Language Models

Learning how LLMs work and how to interact with them through Python applications.

Topics include:

* LLM APIs
* Model parameters
* Tokens
* Temperature
* System prompts
* User prompts
* Model responses

### 3. Prompt Engineering

Learning how to design better prompts for more useful and reliable AI responses.

Examples include:

* Basic prompts
* Prompt templates
* Role-based prompts
* Few-shot prompting
* Structured prompts

### 4. LangChain

Exploring LangChain as a framework for developing applications powered by language models.

Learning concepts such as:

* Models
* Prompts
* Chains
* Runnables
* Output parsers
* Tools
* Agents
* Retrievers

### 5. Embeddings

Learning how text can be converted into numerical vector representations.

```text
Text
 ↓
Embedding Model
 ↓
Vector Representation
 ↓
Similarity Search
```

### 6. Retrieval-Augmented Generation (RAG)

Learning how an AI application can retrieve relevant information from external data and provide it to an LLM as context.

```text
User Question
      ↓
   Retriever
      ↓
Relevant Documents
      ↓
    Context
      ↓
     LLM
      ↓
Generated Answer
```

### 7. AI Agents

Learning how AI agents can use tools to perform tasks and interact with external systems.

## ⚙️ Getting Started

### Clone the Repository

```bash
git clone https://github.com/your-username/your-repository-name.git
```

### Move into the Project

```bash
cd your-repository-name
```

### Create a Virtual Environment

```bash
python -m venv venv
```

### Activate the Environment

**Windows:**

```bash
venv\Scripts\activate
```

**Linux / macOS:**

